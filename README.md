# TMD Chat

Private company / shop / team communication application.

## Current MVP
- Sky Blue + White UI
- Mobile OTP login flow
- Company / Shop / Team structure
- Direct and group chat foundation
- Media/document/voice message foundation
- QR device-linking foundation
- Responsive mobile and desktop interface

## Production roadmap
- Real SMS OTP provider
- WebSocket real-time messaging
- Push notifications
- Cloud file storage
- Android and iOS applications
- Secure phone-to-computer linked devices
